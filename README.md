# VIA LOCAL — MVP Prototype

نسخة أولية Front-end لمنصة VIA LOCAL السياحية.

## المتطلبات
- Node.js إصدار 18 أو أحدث
- npm

## التشغيل
```bash
npm install
npm run dev
```
افتح الرابط الذي يظهر في الطرفية (غالبًا http://localhost:5173).

## إنشاء نسخة إنتاجية
```bash
npm run build
npm run preview
```

## الموجود في النسخة الحالية
- واجهة عربية RTL مع تبديل إلى الإنجليزية.
- تصميم متجاوب للكمبيوتر والموبايل.
- استكشاف وجهات مع بحث وفلاتر: عائلات، خيارات حلال، وإمكانية الوصول.
- حفظ الأماكن في المفضلة (داخل حالة الصفحة فقط).
- ملفات مرشدين محليين وطلب حجز تجريبي.
- قسم الوصول الشامل مع خريطة توضيحية تجريبية.
- تحويل النص إلى صوت عبر Web Speech API في المتصفح.
- طلب إذن الموقع الجغرافي من المستخدم.

## ما هو تجريبي وغير متصل بعد؟
- الأماكن والمرشدون والأسعار والتقييمات بيانات توضيحية وليست بيانات حقيقية أو موثقة.
- لا توجد قاعدة بيانات أو حسابات مستخدمين أو دفع أو حجوزات فعلية.
- الخريطة الحالية رسم توضيحي وليست خريطة جغرافية حية.
- تحويل النص إلى صوت يعتمد على دعم المتصفح والأصوات المثبتة. لا توجد ترجمة للغة الإشارة في هذه النسخة.
- الموقع الجغرافي يُطلب بإذن صريح من المستخدم، لكن لا تُستخدم الإحداثيات بعد لترتيب نتائج حقيقية.

## الخطوة التقنية التالية
1. تصميم API وخادم خلفي مشترك للموقع وتطبيق الموبايل.
2. قاعدة بيانات للأماكن والمرشدين وبيانات الوصول الموثقة.
3. خرائط وموقع جغرافي فعلي مع خيارات خصوصية واضحة.
4. تسجيل دخول وصلاحيات ولوحة إدارة.
5. حجوزات حقيقية، إشعارات، واختبارات أمان وإتاحة.
6. تطبيق Android وiOS يستهلك نفس الـ API.
